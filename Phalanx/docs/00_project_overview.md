# Phalanx: AI-Augmented Endpoint Detection & Response (EDR)

## 1. 프로젝트 비전 (Vision)

**Phalanx**(팔랑크스)는 고대 그리스 중장보병 방진의 빈틈없는 방어와 유기적 협동 체계에서 착안한 **차세대 엔드포인트 탐지 및 대응(EDR, Endpoint Detection & Response) 시스템**입니다.

기존 안티바이러스(AV)가 정적 파일 해시나 시그니처 매칭에 의존하여 메모리 인젝션 및 파일리스(Fileless) 스크립트 공격에 무력화되는 한계를 극복하고, 전통적 EDR 솔루션의 고질적 병목인 경보 피로(Alert Fatigue)와 수동 침해사고 분석(IR) 절차를 **결정론적 저부하 커널 센서**와 **자율 AI 위협 헌팅 에이전트(Autonomous Threat Hunting Agent)**의 하이브리드 결합으로 자동화합니다.

---

## 2. 해결하고자 하는 문제 (Problem Statement)

1. **파일리스 및 스크립트 기반 침투 고도화**:
   * 공격자는 디스크에 악성 바이너리를 생성하지 않고, 오피스 매크로(`winword.exe`)를 통해 정상 윈도우 유틸리티(`powershell.exe`, `cmd.exe`, `mshta.exe`)를 은밀히 스폰하여 메모리 상에서 직접 악성 페이로드를 실행합니다.
   * 전통적인 정적 파일 검사로는 실행 시점의 악의적 프로세스 체인을 차단할 수 없습니다.

2. **기존 보안 관제의 경보 피로 및 지연 (Alert Fatigue)**:
   * 하루 수천 건 이상 쏟아지는 EDR 로그 속에서 30~60%에 달하는 오탐(False Positive)을 사람이 직접 확인하느라 실제 침해 발생 시 골든 타임(수 분 이내)을 놓치는 문제가 발생합니다.

3. **기존 AI 보안 도구의 신뢰성 및 가용성 결여**:
   * 시중의 많은 시도는 외부 클라우드 LLM API에 단순 로그 텍스트를 전달하는 Thin-Wrapper 형태에 그치며, 네트워크 단절(폐쇄망)이나 API 장애 시 방어 시스템 전체가 정지하는 치명적 결함을 안고 있습니다.

## 3. Phalanx의 3대 핵심 엔지니어링 가치

### A. 결정론적 초저지연 커널 텔레메트리와 무손실 버퍼링 (The Muscle)
* Windows **ETW (Event Tracing for Windows)**를 유저모드 C++20으로 안전하게 후킹하여 프로세스 트리, 네트워크 소켓, 모듈 로드 이벤트를 마이크로초 단위로 수집합니다.
* 피크 시 초당 수만 건의 이벤트가 폭주해도 커널 버퍼가 터지지 않도록, 초저지연 실시간 텔레메트리 시스템에서 검증된 **더블 버퍼드 락-스왑(Double-Buffered Lock-Swap)** 메커니즘을 적용하여 락 경합(Lock Contention)을 배제하고 유실율 0%를 달성합니다.

### B. 물리적 운영체제 제어권을 가진 자율 AI 위협 헌터 (The Brain)
* 에이전트는 격리된 텍스트 환경에 머무르지 않고, **실제 OS 레벨의 도구(Tool Calling: 페이로드 다단계 해독, 프로세스 메모리 스캔, 위협 평판 조회, MITRE TTP 매핑, 방화벽 IP 차단)**를 직접 호출하여 증거를 수집합니다.
* ReAct(Reasoning + Acting) 루프를 통해 침해 가설을 검증하고, 위협 확신도(Confidence)가 임계값(90% 이상)에 도달하면 gRPC 양방향 스트림을 통해 프로세스를 0.05초(50ms) 이내에 물리적으로 강제 종료(Kill)하고 네트워크를 격리합니다.

### C. 고가용성 이중화 설계 (Graceful Degradation)
* 인터넷이 차단된 국방/금융 폐쇄망이거나 외부 API 서비스 장애 환경에서도 시스템이 무력화되지 않습니다.
* **1차 반사신경 엔진(Fast Heuristics)**이 0.02초(20ms) 이내에 위협 프로세스를 즉시 동결(Freeze)하고, **결정론적 룰 엔진(Sigma Rule)**이 0.05초(50ms) 이내에 100% 로컬에서 닫힌 루프(Closed-Loop) 강제 종료를 수행하며, **AI 에이전트**는 모호한 회색지대(Unknown/Suspicious)의 심층 분석과 관제 편의(사고 타임라인 리포팅)를 돕는 코파일럿으로 유기적으로 분리 동작합니다.

## 4. 시스템 정량적 목표 (Key Performance Metrics)

| :---------------------- | :------------------------- | :------------------------------------------- |
| **센서 CPU 점유율**          | 평상시 **0.5% 미만**            | 더블 버퍼링, 유저모드 이벤트 스트리밍, 비동기 I/O               |
| **센서 메모리 사용량**          | **30MB 미만**                | C++ POD 구조체 순환 버퍼링, 정적 할당                    |
| **반사신경 동결 지연 (Reflex)** | 이상 감지 후 **20ms 이내 Freeze** | 1차 C++ 휴리스틱 필터 및 Win32 `SuspendThread` 직접 호출 |
| **결정론적 차단 지연 (Kill)**   | 룰 매칭 후 **50ms 이내 Kill**   | 로컬 룰 엔진 판정 및 gRPC 양방향 명령 하달               |
