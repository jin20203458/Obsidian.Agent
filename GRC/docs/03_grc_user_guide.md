# GRC 사용자 기능 매뉴얼 (GRC User Feature Guide)

본 문서는 GRC(GenAI Roleplay Chat) 데스크톱 클라이언트의 7대 핵심 기능(AI 세션 아키텍트, Cognitive Core 3.0 기억 엔진, 캐릭터 스탯창, 하이브리드 로어북, 멀티모달 TTS, AI 추천 답글, 세션 데이터 관리)의 상세 사용법과 동작 원리를 안내합니다.

---

## 1. AI 세션 아키텍트 (Session Architect) 활용법

AI 세션 아키텍트는 한 줄의 입력 키워드를 기반으로 TRPG 세계관, 인물 사전, 스탯창, 초기 시나리오, 그리고 게임 마스터(GM) 지시문을 6단계에 걸쳐 자율 기획하고 검수하는 지능형 저작 엔진입니다.

### 사용 방법
1. 메인 화면 상단의 **AI 세션 아키텍트** 버튼을 클릭합니다.
2. 입력창에 기획하고자 하는 주제 키워드를 입력합니다.
   * 예: `사이버펑크 도시 하수구에서 생존하는 네온 해커`
   * 예: `마왕군에게 멸망 직전인 판타지 왕국의 수석 기사단장`
3. **[자동 시작]** 버튼을 클릭하면 아래 6단계 절차가 순차적으로 수행됩니다.
   * **1단계 (기획 / Planning)**: 장르, 테마, 플레이어(PC) 및 상대 AI(NPC) 핵심 정체성 수립
   * **2단계 (세계관 / Worldview)**: 지리, 세력, 기술/마법 체계, 사회적 규칙 등 마스터 설정 구축
   * **3단계 (로어북 / Lorebook)**: 주요 지명, 조직, 비밀 등 키워드 및 시맨틱 설명 항목 5~8건 생성
   * **4단계 (스탯창 / Status)**: 체력, 마나, 감정, 호감도, 위치 등 초기 상태 계기판 설계
   * **5단계 (초기 시나리오 / Initial Scenario)**: 첫 도입부 배경 묘사 및 AI 캐릭터의 생생한 첫 대사 작성
   * **6단계 (시스템 지침 / GM Directive)**: 접두사 동결(Prefix-Frozen)될 GM 페르소나 및 서사 규칙 확정
4. **AI 감사관 자가 검수 (Self-Review)**:
   * 각 단계가 끝날 때마다 내부 AI 감사관이 JSON 스키마 규격과 설정 간 개연성 모순을 자동 검증합니다. 결함이 감지되면 사용자 개입 없이 자율 보정(`ReviseContentAsync`) 후 다음 단계로 전진합니다.
5. 기획이 완료되면 **[대화 시작]**을 눌러 즉시 롤플레잉 세션으로 진입합니다.

## 2. 인지 코어 3.0 기억 시스템 (Cognitive Core 3.0 Memory System)

GRC는 수백 턴의 장기 롤플레잉을 진행해도 기억 상실, 컨텍스트 윈도우 초과, 프롬프트 캐시 미스(비용 폭발)가 발생하지 않도록 Cognitive Core 3.0 아키텍처를 탑재했습니다.

### 기억 관리 3대 핵심 구조
1. **불변 접두사 동결 (Prefix-Frozen SystemInstruction)**:
   * 시스템 페르소나와 불변 세계관을 `SystemInstruction`에 고정하여 구글 클라우드 및 Gemini API의 프롬프트 캐시(KV Cache) 적중률을 최대 90%까지 극대화합니다.
2. **단기 대화 이력 (Raw History)**:
   * 가장 최근에 나눈 18턴 대화를 원문 그대로 생생하게 유지합니다.
   * 18턴에 도달하면 가장 오래된 8턴을 절삭하여 백그라운드 스레드에서 즉시 사건 팩트 추출을 시작합니다.
3. **사건 불릿 원장 (Single Event Ledger & Gated RAG)**:
   * 절삭된 대화는 **Gemini 3.5 Flash-Lite** 모델에 의해 3~5개의 순수 팩트 불릿(Fact Bullets)으로 압축 추출되며, Google 768차원 다국어 임베딩(`text-multilingual-embedding-002`)과 함께 단일 원장에 영구 누적됩니다.
   * **최근 사건 흐름 (상시 15개)**: 단일 원장의 최신 15개 불릿(`TakeLast(15)`)을 `[제N장]` 시간축 그룹 헤더와 함께 매 턴 프롬프트에 상시 노출하여 서사의 연속성을 보존합니다.
   * **떠오른 과거의 기억 (Gated Salience RAG)**: 최신 15개를 제외한 과거 전체 풀을 대상으로, 매 턴 사용자 입력의 의미론적 유사도(코사인 유사도 $\ge 0.71f$)를 스캔하여 관련된 과거 사건 2건을 시간순으로 자동 회상합니다.
4. **대서사 연대기 (Macro Chronicle 즉시 병합)**:
   * 1개 챕터(80턴)가 마감되는 즉시 해당 챕터의 불릿들을 **Gemini Pro** 모델에 비동기 전달하여 1,500자 이내의 산문 대서사 연대기로 영구 병합 보존합니다. (과거 레거시 3챕터 대기 큐는 전면 폐지되었습니다.)

## 3. 캐릭터 스탯창 및 바이-템포럴 투영 (Status System)

대화창 우측의 스탯창은 캐릭터의 상태, 감정, 호감도, 현재 위치를 실시간으로 표시하는 계기판입니다.

### 주요 특징
* **비동기 0초 지연 파싱**: 대화 수신 완료 시 백그라운드 태스크에서 상태 변화를 안전하게 파싱하여 갱신하므로 메인 대화 렌더링에 일체 지연을 유발하지 않습니다.
* **시간 인식 엔티티 투영 (Bi-Temporal Entity Projection)**:
   * 상태창에 등록된 인물들의 현재 상태와 수치 변화를 `- 인물: 상태 (수치)` 형태로 간결하게 프롬프트에 주입하여 AI가 인물들의 최신 관계성과 상태를 왜곡 없이 서사에 반영합니다.

## 4. 하이브리드 로어북 (Hybrid Lorebook) RAG

로어북은 대화 중 특정 지명, 인물, 조직, 마법 등의 설정이 언급되었을 때 관련 설정을 컨텍스트에 동적으로 주입하는 인출 엔진입니다.

### 로어북 항목 등록 및 동작 원리
1. 대화창 상단의 **[로어북 편집]** 버튼을 클릭하여 새 항목을 등록합니다.
   * **이름/키워드**: 감지할 엔티티 명칭 및 동의어 (예: `엘리시움`, `흑마법`)
   * **카테고리**: 지명, 인물, 사건, 아이템 등 분류
   * **설정 내용**: 해당 항목의 상세 비하인드 설정
2. **2단계 하이브리드 인출 파이프라인**:
   * **1차 키워드 스캔**: 사용자 입력 및 최근 대화에 정규식(Regex) 키워드가 완전 일치할 경우 즉시 인출.
   * **2차 768차원 임베딩 유사도 검색**: 키워드가 직접 언급되지 않더라도 시맨틱 코사인 유사도($\ge 0.68f$)가 높은 관련 설정을 자동 인출.
   * **3턴 스티키(Sticky) 보존**: 한 번 활성화된 로어북은 3턴 동안 프롬프트에 유지되어 대화 맥락이 끊기지 않습니다.
   * **활성 인물 필터링**: 최근 4턴 대화 및 현재 입력에 실제 등장하는 인물만 상태창에서 매칭하여 최대 3,000토큰 예산 초과를 원천 방어합니다.

## 5. 멀티모달 감정 연기 TTS (Text-to-Speech)

Google Cloud Vertex AI가 연동된 경우 AI 캐릭터의 대사를 감정이 실린 실시간 오디오로 합성하여 재생합니다.

### 동작 및 설정
* **설정 방법**: 구글 클라우드 콘솔 서비스 계정에 `Vertex AI 사용자` 및 `Cloud Text-to-Speech API 사용자` (또는 `편집자`) 권한을 부여한 키 파일(`.json`)을 설정 메뉴에서 등록하고 **[TTS 기능 활성화]**를 체크합니다.
* **보이스 프리페치 및 자막 동기화 (Sync Hold)**:
   * 텍스트 스트리밍 중 대사 구간(`"..."`)을 감지하면 백그라운드에서 오디오를 즉시 사전 생성(Prefetch)합니다.
   * UI 소비자가 대사 끝 따옴표에 도달하면 음성을 재생하며, 음성 재생이 완료될 때까지 지문 텍스트 출력을 안전하게 일시 정지(Hold)하여 목소리와 자막의 완벽한 박자를 유지합니다.

## 6. AI 추천 답글 생성 (Reply Suggestion)

AI 응답 생성이 완료된 직후 유저가 선택할 수 있는 3가지 몰입형 대화 선택지를 백그라운드에서 자동 제안합니다.

### 활용 지침
* **지문 선택**: 추천 지문을 클릭하면 입력창에 자동 삽입되어 한 번의 클릭으로 서사를 속도감 있게 이어갈 수 있습니다.
* **지문 편집**: 제안된 지문을 불러온 뒤 세부 대사나 행동을 유저가 자유롭게 가필하여 전송할 수 있습니다.

## 7. 데이터 저장 및 O(1) 파일 무결성

* **저장 위치**: 모든 세션 및 대화 이력 파일은 애플리케이션 루트 내 `Sessions/` 디렉터리에 보관됩니다.
* **O(1) 무부하 로깅**: 대화 이력 영구 저장 시 전체 JSON 파일을 역직렬화하지 않고 바이너리 역방향 탐색(`]`)을 통해 즉시 바이트 단위로 추가(Append)하므로, 수백 턴의 대화가 쌓여도 UI 멈춤이나 지연이 전혀 발생하지 않습니다.
* **백업 및 이동**: 세션을 백업하거나 PC를 이동할 경우 `Sessions/` 폴더만 복사하여 새 프로그램 디렉터리에 붙여넣으면 모든 기억과 설정이 100% 무손실 복구됩니다.
