# GRC 사용자 기능 매뉴얼 (GRC User Feature Guide)

> **부제**: GRC 기능별 상세 사용 지침 및 매뉴얼

---

## 1. AI 세션 아키텍트 (Session Architect) 활용법

AI 세션 아키텍트는 한 줄의 입력 키워드를 기반으로 TRPG 세계관, 인물 사전, 스탯창, 초기 시나리오를 자율 기획하고 검수하는 기능입니다.

### 사용 방법
1. 메인 화면 상단의 **AI 세션 아키텍트** 버튼을 클릭합니다.
2. 입력창에 기획하고자 하는 주제를 입력합니다.
   * 예: `사이버펑크 도시 하수구에서 생존하는 네온 해커`
   * 예: `마왕군에게 멸망 직전인 판타지 왕국의 수석 기사단장`
3. **[자동 시작]** 버튼을 클릭하면 아래 4단계 절차가 수행됩니다.
   * **1단계 (기능 기획)**: 장르, 세계관 분위기, 플레이어(PC) 및 상대 AI(NPC) 기본 설정 생성
   * **2단계 (로어북 지식)**: 주요 지명, 조직, 세계관 규칙 등 사전 항목 생성
   * **3단계 (시나리오)**: 첫 도입부 지문 및 AI 캐릭터의 초기 대사 작성
   * **4단계 (AI 감사관 검수)**: 설정 간 모순 여부를 검토하고 자율 보정
4. 기획이 완료되면 **[대화 시작]**을 눌러 해당 세션으로 진입합니다.

## 2. 3단계 기억 파이프라인 (3-Tier Memory System)

GRC는 누적 대화량이 늘어나도 컨텍스트 보존과 토큰 효율을 유지하기 위해 3단계 기억 압축 파이프라인을 구동합니다.

### 기억 관리 구조
* **단기 기억 (Raw History)**: 최근 18턴 대화를 원본 그대로 유지합니다.
* **중기 기억 (Chapter Plot)**: 대화 누적 시 10턴 단위로 현재 챕터의 줄거리를 압축하여 보존합니다.
* **장기 기억 (Chronicle)**: 챕터 누적 시 핵심 인과관계 및 대사건만 선별하여 1,500자 이내의 연대기로 영구 보존합니다.

## 3. 캐릭터 스탯창 및 실시간 자동 갱신 (Status System)

대화 창 우측의 스탯창은 캐릭터의 상태, 감정, 호감도, 현재 위치를 실시간으로 표시하는 계기판입니다.

### 주요 특징
* **비동기 0초 지연 파싱**: 대화 수신 완료 시 백그라운드 스레드에서 대화 맥락, 호감도, 감정선 및 장소 변화를 파싱하여 스탯창을 갱신합니다. 메인 대화 렌더링 지연을 유발하지 않습니다.
* **관계성 변동**: 대화 진행 상황에 따라 캐릭터의 호감도 수치 및 칭호(예: `경계하는 낯선이` -> `신뢰하는 동료`)가 자동으로 업데이트됩니다.

## 4. 로어북 (Lorebook: 인물/세계관 사전) 기능 및 편집

로어북은 대화 중 특정 키워드가 등장했을 때 관련 설정 및 비하인드 지식을 컨텍스트에 동적으로 주입하는 기능입니다.

### 로어북 항목 등록 방법
1. 대화창 상단의 **[로어북 편집]** 버튼을 클릭합니다.
2. **[+ 새 항목 추가]**를 눌러 아래 정보를 설정합니다.
   * **트리거 키워드**: 대화 중 감지할 단어 (예: `붉은 보석`, `아르카디아`)
   * **설정 내용**: 키워드 감지 시 주입할 비하인드 설정 (예: `붉은 보석은 마왕의 영혼이 봉인된 마도구로, 캐릭터는 이 보석을 극도로 두려워함`)
3. 저장 후 대화에서 해당 키워드가 언급되면 설정 내용이 최우선 컨텍스트로 자동 주입됩니다.

## 5. 멀티모달 감정 연기 TTS (Text-to-Speech)

Google Cloud Vertex AI가 연동된 경우 AI 캐릭터의 대사를 멀티모달 오디오로 합성하여 재생합니다.

### 동작 및 설정
* **설정 방법**: 설정 메뉴에서 Vertex AI 연동 및 **[TTS 기능 활성화]**를 선택합니다.
* **자막-음성 동기화 (Sync Hold)**: 텍스트 스트리밍 중 대사 구간(`"..."`)을 감지하면 음성을 선행 생성(Prefetch)하고, 오디오 재생이 완료될 때까지 자막 출력을 대기시켜 싱크를 맞춥니다.

## 6. AI 추천 답글(선택지) 생성 (Reply Suggestion)

AI 대사 출력이 완료된 직후 유저가 선택할 수 있는 3가지 대화 선택지 지문을 생성합니다.

### 활용 지침
* **지문 선택**: 추천 지문을 클릭하면 입력창에 자동 삽입되어 빠른 대화 진행이 가능합니다.
* **지문 수정**: 추천 지문을 입력창에 불러온 후 유저가 내용을 추가/수정하여 전송할 수 있습니다.

---

## 7. 데이터 저장 및 백업 가이드

* **저장 위치**: 모든 세션 및 대화 이력 파일은 포터블 폴더 내 `Sessions/` 디렉터리에 보관됩니다.
* **데이터 이동/백업**: 프로그램 위치를 이동하거나 업데이트를 진행할 경우 `Sessions/` 폴더를 복사하여 동일 위치에 배치하면 기존 데이터가 유지됩니다.
