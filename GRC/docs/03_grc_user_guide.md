# GRC 사용자 기능 매뉴얼 (GRC User Feature Guide)

본 문서는 GRC(GenAI Roleplay Chat) 데스크톱 클라이언트의 7대 핵심 기능(AI 세션 아키텍트 2.0, Cognitive Core 3.0 기억·시드 엔진, 캐릭터 상태창, 구조화 하이브리드 로어북, 멀티모달 감정 TTS, 4-슬롯 AI 추천 답글, 세션 데이터 및 관측 로그 관리)의 상세 사용법과 동작 원리를 안내합니다.

---

## 1. AI 세션 아키텍트 2.0 (Session Architect 2.0) 활용법

AI 세션 아키텍트 2.0은 한 줄의 입력 키워드를 기반으로 TRPG 마스터 세계관, 구조화 로어북(인물·장소·아이템·세계관), 오프닝 시나리오, 초기 상태창 및 게임 마스터(GM) 시스템 지시문을 **`Gemini 4.0 Pro`(`gemini-4-argon`, `ThinkingLevel.high`, 최대 32,768 출력 토큰) 기반 4단계 통합 파이프라인(총 5회 API 호출)**으로 자율 설계하고 C# 결정론적 무결성 관문으로 검수하는 지능형 저작 엔진입니다.

### 사용 방법
1. 메인 화면 상단의 **[AI 세션 아키텍트]** 버튼(또는 웰컴 화면의 **[AI 세션 만들기]**, 진행 중인 대화창 상단의 세션 아키텍트 수정 아이콘)을 클릭합니다.
2. 하단 입력창에 기획하고자 하는 장르, 분위기, 시작 컨셉을 자유롭게 입력하고 **[전송]**(또는 `Enter`)을 누릅니다.
   * 예: `사이버펑크 도시 하수구에서 생존하는 네온 해커`
   * 예: `평소엔 밝고 유쾌한 아카데미 학원물이지만, 학원 도시 이면에는 어두운 비밀이 도사린 서브컬처 판타지`
3. **4단계 통합 생성 파이프라인**:
   * 우측 하단의 **[자동]** 토글이 기본 활성화(`IsAutoMode = true`)되어 있어, 컨셉만 입력하면 스포일러 방지 요약 카드만 표시한 채 아래 4단계를 연속 완주하고 즉시 대화 화면으로 진입합니다(수동 모드로 전환 시 단계마다 직접 내용을 확인·수정하고 **[승인, 다음 단계]**로 진행 가능):
   * **1단계 (`1. 청사진·세계관` — 1회 호출)**: 4대 번호 섹션 개조식 마스터 세계관(`worldviewOutline`)과 10~18개 그물망 로어북 기획(`lorebookPlan`: 주요 인물 4~8명, 단일 장소 3~5곳, 단일 아이템/단서 2~4개, 세계관/조직/사건 1~3개 및 상호 연결망 `connectedEntities`)을 공동 설계합니다.
   * **2단계 (`2. 로어북` — 2-Wave 2회 호출)**: Wave 1에서 모든 비인물(장소·아이템·세계관) 무대 인프라(4필드 구조화 스키마)를 1회 통합 호출로 먼저 확정한 뒤, Wave 2에서 확정된 무대 설정 위에 모든 등장인물 전원(11필드 구조화 스키마, 인물 간 화법·외양 앙상블 분산 적용)을 1회 통합 캐스팅 호출로 생성합니다.
   * **3단계 (`3. 오프닝 시나리오` — 1회 호출)**: 확정된 세계관과 로어북 전문을 반영하여 주인공(PC)이 첫 행동을 선택해야 하는 직면 순간까지의 도입부를 독립된 순수 문학 산문(`text/plain`)으로 집필합니다.
   * **4단계 (`4. 상태창·시스템 지시` — 1회 호출 + 하이브리드 컴파일)**: 오프닝 본문을 역분석하여 초기 스탯(`stats`), 상태창 수치 갱신 가이드(`guide`), Turn 0 현장 상태(`initialChars`, 단일 시작 장소 `initialPlaces` 1곳, 실제 휴대 소지품 `initialItems` 0~4개), 그리고 세션 특화 비수치 GM 수칙 4·5번(`genreDirectives`)을 추출하고 코어 3대 헌법(`CoreSystemDirectivesHeader`)과 결합한 뒤 768차원 로어북 임베딩을 병렬 발급합니다.
4. **100% C# 결정론적 무결성 관문 및 외과수술식 보정 (`ReviewStepContentAsync` & `ReviseLorebooksSurgicallyAsync`)**:
   * 각 단계 완료 시 LLM 재호출 없이 C# 파서와 정규식 기반의 결정론적 검수 관문(API 호출 0회)이 즉시 가동됩니다. 기획된 로어북 항목 누락이나 인물 필수 대사(`"..."`) 누락 등 구조적 결함이 감지되면 `[수정 대상: 항목명]`을 지정해 해당 항목만 외과수술식으로 핀포인트 재생성·병합합니다.

## 2. 인지 코어 3.0 기억 및 스토리 시드 시스템 (Cognitive Core 3.0)

GRC는 수백 턴의 장기 롤플레잉을 진행해도 기억 상실, 컨텍스트 윈도우 초과, 프롬프트 캐시 미스(비용 폭발)가 발생하지 않도록 Cognitive Core 3.0 아키텍처를 탑재했습니다. 대화창 상단의 **[기억 열람]** 버튼(시계 아이콘)을 통해 누적된 장기 연대기와 현재 챕터의 사건 불릿 원장을 언제든 열람할 수 있습니다.

### 기억 관리 및 서사 추진 핵심 구조
1. **불변 접두사 동결 (Prefix-Frozen SystemInstruction)**:
   * 시스템 페르소나(GM 5대 수칙), 불변 마스터 세계관(`<master_setting>`), 서술 포맷 규칙(`FormatRule`)을 `SystemInstruction`에 고정하고, 동적 기억과 로어북은 최신 유저 메시지 직전의 동적 슬롯에 패킹하여 프롬프트 캐시(KV Cache) 적중률을 극대화하고 문체 오염을 차단합니다.
2. **단기 대화 이력 (Raw History)**:
   * 가장 최근에 나눈 14개 메시지(7턴 대화, `ShortTermThreshold = 14`)를 원문 그대로 유지합니다.
   * 14개 메시지에 도달하면 가장 오래된 8개 메시지(4턴, `MemoryCompressionChunkSize = 8`)를 절삭하여 백그라운드 스레드에서 사건 팩트 추출을 시작합니다.
3. **사건 불릿 원장 (Single Event Ledger & Gated RAG)**:
   * 절삭된 8개 메시지는 **Gemini 3.5 Flash-Lite** 모델에 의해 구간 서사 밀도(`density: LOW | MEDIUM | HIGH`)를 선행 판정한 뒤, 밀도에 맞는 **2~5개**(`LOW: 2개`, `MEDIUM: 3개`, `HIGH: 4~5개`)의 자기완결형 인과 팩트 불릿으로 압축 추출되며, Google 다국어 통합 임베딩(`gemini-embedding-001`, MRL 768차원, 서울 `asia-northeast3` 리전)과 함께 단일 원장에 영구 누적됩니다.
   * **최근 사건 흐름 (`<internal_chronicle_facts>`, 상시 20~52개 무중복 노출)**: 아직 장기 연대기로 요약되지 않은 미요약 챕터의 불릿 전량(`Chapter > _lastSummarizedChapter`)을 `[제N장]` 시간축 그룹 헤더와 함께 매 턴 프롬프트에 상시 노출하여 최근 25~64턴의 서사 연속성을 보존합니다.
   * **과거 회상 RAG (`<recalled_history>`, `GatedRAGRetriever`)**: 장기 연대기로 요약 완료된 과거 챕터 풀(`Chapter <= _lastSummarizedChapter`)만을 대상으로, 매 턴 사용자 입력(초단답·자동 진행 시 직전 서술 마지막 문단 폴백)과의 코사인 유사도($\ge 0.80f$) 및 채택 불릿 간 중복 필터링($< 0.90f$)을 거쳐 최대 5건의 독립 과거 사건을 원장 인덱스 시간순으로 자동 회상합니다.
4. **대서사 연대기 (Macro Chronicle 무중복 지연 병합)**:
   * 10회 중기 압축(80개 메시지 = 40턴, `MediumTermThreshold = 10`)마다 새 챕터 번호로 전환됩니다. 신규 챕터에 불릿이 20개(`LongTermArchiveTriggerBullets = 20`) 이상 축적되면 직전 챕터까지 즉시 비동기 병합하며, 잔잔한 진행으로 20개 미만인 채 40턴 챕터 마감을 맞이한 경우에도 전전 챕터(`_chapterCount - 2`)까지 **Gemini 4.0 Pro**(`gemini-4-argon`, `ThinkingLevel.medium`) 모델에 전달하여 2,500자 이내의 문학적 산문 연대기로 병합하고 RAG 아카이브로 이관합니다.
5. **사건 해결 변수 기반 3대 스토리 시드 엔진 (`<story_seeds>`)**:
   * 장면이 일단락(`isSceneResolved = true`, 장소 이동, 또는 `days` 이상 시간 경과)되거나 유저가 **[스킵]**(빠른 진행)을 켜면 3턴 동안 유지되는 시드 창을 개설하여, 제시 횟수 오름차순(Head-of-Line Blocking 방지)으로 ① **`[미등장 인물 조우]`(`Pool A`)**, ② **`[장소/사건 훅]`(`Pool B`)**, ③ **`[동료 유대 심화]`(`Pool C`: 현장 동석 동료 `Slot C-Local` + 타 거점 부재 동료 `Slot C-Remote`, 호감도 30+ 1단계 `BOND` 및 60+ 2단계 `BOND_SECRET`)** 시드를 동적 공급합니다.

## 3. 캐릭터 상태창 및 바이-템포럴 투영 (Status System)

대화창 우측 상단의 방패 아이콘(**[상태창]** 버튼)을 클릭하면 현재 위치, 플레이어 주요 스탯 수치, 보유 소지품(인벤토리), 등장인물별 현재 상태 및 감정·행동을 실시간으로 확인할 수 있습니다.

### 주요 특징
* **비동기 0초 지연 파싱 및 자동 재시도 (`StatusAI`)**: 매 턴 스트리밍 완료 직후 백그라운드 태스크에서 **Gemini 3.5 Flash-Lite**(`ThinkingLevel.low`)가 최신 1턴의 변화를 파싱하며, 일시적 오류 시 지수 백오프(`2000ms`, `5000ms`)로 자동 재시도합니다.
* **시간 인식 엔티티 투영 (`BiTemporalEntityProjector`) 및 정합성 가드**:
   * 등장인물의 현재 상태와 매칭된 관계도 수치는 `<entity_relationship>` 슬롯에 `- 인물(이름): 상태 (수치)` 형태로 투영하고, 나머지 주요 수치·단일 현재 위치(`currentPlace`)·실제 보유 소지품(`items`)은 `<current_state>` 슬롯에 중복 없이 분리 주입합니다.
   * 주인공 고유명사 및 플레이어 지칭어는 NPC 목록(`Chars`)에서 자동 필터링되며, 장기 시간 경과(`elapsedTime`: `days` / `months` / `years`) 턴에는 코드 레벨 호감도 급등 상한과 다음 턴 시간 경과 연출 지시(`time_skip_progression`)가 자동 적용됩니다.

## 4. 구조화 하이브리드 로어북 (Hybrid Lorebook) RAG 및 3단계 스포일러 마스킹

로어북은 세계관 속 인물, 장소, 아이템, 세력/규칙, 기억 설정을 구조화하여 보관하고, 대화 맥락에 맞춰 프롬프트에 동적으로 주입하는 핵심 지식 엔진입니다.

### 로어북 편집 및 동작 원리
1. 대화창 상단의 책 아이콘(**[로어북 관리]** 버튼)을 클릭하면 **카테고리별 전용 구조화 편집창(`EditLorebookWindow`)**이 열리며, 하단에서 `<world_lore>` 실제 주입 형태를 실시간 미리보기로 확인할 수 있습니다.
   * **`인물` 카테고리 (11필드 구조화 폼 & 호감도 3단계 스포일러 마스킹)**:
     - **공개 1단계 (호감도 `< 30`, 조우 시 즉시 공개)**: 신분/정체성 요약(`RoleSummary`), 외양/버릇(`Appearance`), 표면 페르소나(`SurfacePersona`), PC 초기 접점(`InitialContact`), 타 인물/세력 관계(`OtherRelations`), 말투 특징(`SpeechTone`), 일상 대사 샘플(`EverydayQuote`)
     - **공개 2단계 (호감도 `30~59` 해금)**: 유대 심화 발단 계기(`BondTrigger`) 및 완수 후 관계 변화(`BondPayoff`) 추가 공개
     - **공개 3단계 (호감도 `>= 60` 완전 해금)**: 심층 내면 동기·비밀(`InnerMotivation`) 및 감정 고조 대사 샘플(`EmotionalQuote`) 완전 해금
   * **`장소` / `아이템` / `세계관` 카테고리 (4필드 구조화 폼)**: 핵심 정체성 요약(`IdentitySummary`), 감각/외관 디테일(`SensoryDetails`), 고유 규칙/원리(`RulesAndPrinciples`), 서사 훅(`NarrativeHook`)
   * **`기억` / 기타 카테고리 (`FreeText` 자유 서술 폼)**: 대화 중 특정 메시지 우클릭 메뉴의 **[기억으로 저장]** 기능을 통해 자동 추출된 사건 기억이나 자유 형식 설정을 보관합니다.
2. **5,000토큰 예산 기반 5단계 계층적 하이브리드 인출 (`HybridLorebookRetriever`)**:
   * 호감도 단계별 마스킹이 선행 적용된 실제 텍스트 길이를 기준으로 **최대 5,000토큰**(`DefaultMaxTokenBudget = 5000`) 예산 내에서 아래 우선순위대로 인출합니다:
     1. **시드 고정 인물**: 이번 턴 제시된 `CHAR:` 조우 시드 대상 인물의 1단계 로어북 최우선 보장
     2. **Sparse 이름/키워드 매칭**: 직전 AI 응답(Turn 1은 오프닝 시나리오) + 현재 유저 입력에 정식 명칭 또는 트리거 키워드가 어절 경계(한국어 조사 허용)로 매칭된 항목 (**트리거 턴 포함 총 3턴 Sticky 유지**, `DefaultStickyTurns = 2`)
     3. **확정 보충 (현재 장소 & 활성 인물)**: 현재 위치(`currentPlace`)와 단기 기억(14개 메시지)·최근 사건 불릿(3개)·현재 입력에 어절 단위로 등장한 상태창 인물
     4. **Sticky 잔존**: 직전 턴 Sparse 매칭으로 활성화된 잔존 로어북 (Dense 매칭에는 Sticky 미부여)
     5. **Dense 768차원 시맨틱 보충**: 코사인 유사도 $\ge 0.75f$ 상위 최대 3개(`DefaultMaxDenseMatches = 3`, 아직 만나지 않은 미등장 인물은 Dense 인출에서 원천 배제하여 조기 스포일러 차단)
   * **참조 개체 1줄 요약 자동 병기 (`AppendReferencedEntitySummaries`)**: 이번 턴 채택된 로어북 본문 안에 이름이 언급되었으나 직접 채택되지 않은 타 로어북 개체가 있으면, 해당 개체의 1줄 핵심 정의(`RoleSummary` / `IdentitySummary`)를 `<world_lore>` 하단에 자동 병기하여 문맥 오인을 방지합니다.

## 5. 멀티모달 감정 연기 TTS (Text-to-Speech) 및 사운드 연출

AI 캐릭터의 대사를 상황과 감정이 실린 실시간 오디오(`gemini-3.1-flash-tts-preview`)로 합성하여 재생하며, 세계관 테마별 배경음악(BGM) 및 타이핑 효과음(타건음)과 유기적으로 연동됩니다.

### 동작 및 설정
* **설정 방법**: 환경 설정 화면에서 **[음성 읽어주기(TTS) 활성화]**를 체크하고, 읽어주기 언어(**`Korean`** 또는 **`Japanese`**)와 14종의 성우 보이스 캐릭터(`Zephyr`, `Achernar`, `Aoede`, `Autonoe`, `Callirrhoe`, `Despina`, `Erinome`, `Gacrux`, `Kore`, `Laomedeia`, `Leda`, `Pulcherrima`, `Sulafat`, `Vindemiatrix`) 중 원하는 음성을 선택한 뒤 **[음성 미리듣기]**로 테스트할 수 있습니다.
* **보이스 프리페치, 일본어 구어체 번역 및 자막 동기화 (Sync Hold)**:
   * 텍스트 스트리밍 중 대사 구간(`"..."`)을 감지하면 백그라운드에서 즉시 오디오 생성을 발주(Prefetch)합니다(일본어 모드 선택 시 `Gemini 3.5 Flash-Lite`가 캐릭터 어투를 살려 자연스러운 일본어 구어체로 선행 번역 후 합성).
   * UI 타이핑 소비자가 대사 구간에 진입하면 타건음을 자동으로 음소거(Mute)하고, 닫는 따옴표에 도달하면 생성 완료된 음성을 즉시 재생합니다. 음성 재생이 끝날 때까지 다음 지문 텍스트 출력을 일시 대기(Hold)하여 성우 음성과 자막의 박자를 일치시킵니다.

## 6. 4-슬롯 AI 추천 답글 (Reply Suggestion) 및 대화 편의 도구

대화 입력창 하단의 **[추천답변]** 토글을 켜두면, AI 응답 생성이 완료될 때 백그라운드에서 **Gemini 3.5 Flash-Lite**(`ThinkingLevel.low`)가 현재 상황과 유저의 기존 말투(`~한다` 지문체, 반말/존댓말 어미)를 분석하여 **4가지 기능적 선택지**를 즉시 제안합니다.

### 4가지 추천 슬롯 및 입력 보조 도구
1. **4-슬롯 추천 답글 구성**:
   * **1번 [정면 호응·현재 흐름 심화]**: 직전 NPC의 대사·감정·요구에 정면으로 호응하며 대화를 심화하는 선택지
   * **2번 [주도권 전환·분위기 환기]**: 역질문이나 능동적인 태도로 대화 주도권을 가져오는 선택지
   * **3번 [현장·소지품·로어 특징 활용]**: 실제 보유 소지품이나 현장 지형지물·상대방의 외형 특징을 활용하는 행동 선택지
   * **4번 [국면 전환·다음 동선 출발]**: 정체된 장면을 마무리하고 가용 스토리 시드(`<available_story_seeds>`)나 타 거점으로 이동을 시작하는 선택지
   * 제안된 선택지를 클릭하면 입력창에 즉시 복사되며, 그대로 전송하거나 자유롭게 가필하여 전송할 수 있습니다.
2. **입력창 하단 및 메시지 우클릭 편의 기능**:
   * **[스킵] (`fast_forward`)**: 반복적인 이동·과정을 압축하여 다음 핵심 사건이나 의사결정 시점까지 빠르게 진행합니다.
   * **[대사] / [속마음]**: 커서 위치에 대사용 큰따옴표(`""`) 또는 속마음용 낫표(`「」`)를 즉시 삽입합니다.
   * **빈 입력 자동 진행 (`auto_continue`)**: 입력창을 비운 채 전송 버튼을 누르면 유저의 기존 기조를 유지한 채 AI가 다음 장면을 한 단계 이어 서술합니다.
   * **메시지 우클릭 컨텍스트 메뉴**: 개별 말풍선을 우클릭하여 **내용 복사**, **메시지 삭제**(최신 턴 삭제 시 상태창 스냅샷 자동 롤백), **재전송(리롤)**, **평행세계 분기 생성(`_Branch` 세션 복제)**, **로어북 기억으로 저장**을 수행할 수 있습니다.
   * **일러스트 스튜디오 (`Plus` 확장 배포판 전용)**: 시작 화면 상단의 **[일러스트 스튜디오]** 버튼을 통해 세션과 무관하게 `WAI-illustrious-SDXL v17.0` 규격의 3행 6슬롯 마스터 프롬프트 조립, 캐릭터 보관함 관리, AI 슬롯 추출·부분 수정을 수행할 수 있습니다.

## 7. 데이터 저장 구조 및 O(1) 파일 무결성

* **세션별 독립 저장 위치**: 모든 세션 데이터는 애플리케이션 루트 내 `Sessions/<세션폴더명>/` 디렉터리에 세션별로 격리 보관됩니다:
   * `Preset.json`: 세계관, 구조화 로어북(768차원 임베딩 포함), 시스템 프롬프트, 스탯 갱신 가이드
   * `Session.json`: 단기 기억 버퍼, 단일 사건 불릿 원장(`EventLedgers`), 장기 연대기(`LongTermSummary`), 상태창 및 스토리 시드 진행 상태 (`.tmp` 임시 파일 기록 후 원자적 `File.Replace` 교체로 파일 손상 방지)
   * `FullHistory.json`: 전체 대화 원문 영구 기록
   * `MemoryLog.txt` & `TokenLog.csv`: 매 턴 로어북/RAG/시드/상태 변화 인과를 기록하는 블랙박스 진단 로그 및 API 호출 목적별(`TokenLogScope`) 토큰/캐시 적중 통계 로그
* **O(1) 무부하 로깅 (`FullHistoryLogger`)**: 대화 이력 영구 저장 시 전체 JSON 파일을 역직렬화하지 않고 바이너리 역방향 탐색(`]`)을 통해 즉시 바이트 단위로 추가(Append)하므로, 수백 턴의 대화가 쌓여도 UI 멈춤이나 GC 스파이크가 전혀 발생하지 않습니다.
* **백업 및 이동**: 세션을 백업하거나 다른 PC로 이동할 경우 `Sessions/` 폴더만 복사하여 새 프로그램 디렉터리에 붙여넣으면 모든 기억과 설정이 100% 무손실 복원됩니다.
