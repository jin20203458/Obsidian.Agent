# GRC 사용자 퀵스타트 가이드 (User Quick Start Guide)


---

## 1. 다운로드 및 압축 해제

1. GRC 공식 저장소의 Releases 페이지에서 최신 버전의 **`GRC_v3.0.0_Portable.zip`**(일반판) 또는 **`GRC_v3.0.0_Plus_Portable.zip`**(일러스트 스튜디오 포함 확장판) 파일을 다운로드합니다.
2. 다운로드한 ZIP 파일의 압축을 대상 폴더(예: `C:\GRC\`)에 먼저 완전히 해제합니다.
   * **주의**: ZIP 파일 내부에서 직접 `GRC.exe`를 실행하면 파일 경로 오류가 발생하므로 반드시 압축 해제 후 실행해야 합니다.

---

## 2. 프로그램 실행 (`GRC.exe`)

1. 압축이 해제된 폴더 내부에서 **`GRC.exe`**를 실행합니다.

### Windows SmartScreen 경고 대처법
코드 서명 미적용 오픈소스 특성상 첫 실행 시 **"Windows가 PC를 보호했습니다"** 경고창이 표시될 수 있습니다.

1. 경고창 내부의 **`추가 정보`**를 클릭합니다.
2. 창 하단에 표시되는 **`실행`** 버튼을 클릭합니다.
3. GRC는 개인정보를 수집하지 않는 MIT 라이선스 오픈소스 프로그램입니다.

---

## 3. 초기 1회 API 키 등록 방법

프로그램 실행 후 우측 상단의 톱니바퀴(**설정**) 아이콘 버튼 또는 첫 실행 웰컴 화면의 **[API 키 설정하기]** 버튼을 클릭하여 환경 설정 화면으로 이동합니다.

### 방법 A: Google AI Studio 키 사용 (간편 설정)
1. 설정 화면의 **[API 키 발급받기]** 버튼을 클릭하거나 Google AI Studio 페이지(https://aistudio.google.com/apikey)에 접속하여 API Key를 발급받습니다.
2. 설정 화면 최상단의 **`Google Cloud Vertex AI 인증 방식 사용`** 체크박스를 **해제**합니다(초기 기본값은 체크 상태이므로 AI Studio 단독 사용 시 반드시 해제해야 합니다).
3. **Gemini API Key (AI Studio 전용)** 입력창에 발급받은 키를 붙여넣습니다.
4. **[연결 시험]** 버튼을 눌러 `PASS: LLM 연결 성공` 메시지를 확인한 뒤, 하단의 **[설정 저장하기]**를 클릭합니다.

### 방법 B: Google Cloud Vertex AI 사용 (권장 / 크레딧 연동)
1. 구글 클라우드 콘솔 IAM 및 관리자 메뉴에서 서비스 계정을 생성하고 비공개 키 파일(`.json`)을 다운로드합니다.
   * **서비스 계정 역할(Role) 설정**: `Vertex AI 사용자`(`Vertex AI User`) 및 `Cloud Text-to-Speech API 사용자` 역할을 부여합니다(또는 `편집자` 역할 사용 가능).
2. GRC 환경 설정 화면에서 **`Google Cloud Vertex AI 인증 방식 사용`** 체크박스가 체크된 상태인지 확인합니다.
3. **[서비스 계정 키 파일 (google-credentials.json) 선택...]** 버튼을 클릭하여 다운로드한 `.json` 파일을 선택하면 `Config/google-credentials.json`으로 자동 등록됩니다.
4. **구글 클라우드 Project ID (Vertex AI 전용)**를 입력합니다.
   * **리전 자동 라우팅**: 주력 LLM(`global`), 768차원 한국어 다국어 임베딩(`asia-northeast3` 서울 리전), 멀티모달 TTS(`us-central1`) 엔드포인트가 내부적으로 자동 분리 연동되므로 별도의 리전 설정이 필요하지 않습니다.
5. **[연결 시험]** 및 **[음성 미리듣기]**로 정상 동작을 확인한 뒤 **[설정 저장하기]**를 클릭합니다.

## 4. 세션 생성 및 대화 시작

1. 메인 화면 상단의 **[AI 세션 아키텍트]** 버튼(또는 웰컴 화면의 **[AI 세션 만들기]**, 수동 생성 시 **[새 대화 시작]**)을 클릭합니다.
2. 하단 입력창에 플레이하고 싶은 장르나 주제 키워드를 한 줄 입력하고 **[전송]**(또는 `Enter`)을 누릅니다.
   * 우측 하단의 **[자동]** 모드가 기본 활성화되어 있어, **4단계 통합 파이프라인(1. 청사진·세계관 -> 2. 로어북 -> 3. 오프닝 시나리오 -> 4. 상태창·시스템 지시)**과 C# 결정론적 무결성 검수를 스포일러 없이 자동 완주한 뒤 즉시 본편 대화 화면으로 진입합니다.
   * 단계별 기획안과 로어북을 직접 확인하고 수정하며 진행하려면 우측 하단의 **[자동]** 토글을 끈 뒤 단계마다 **[승인, 다음 단계]** 버튼을 눌러 진행할 수 있습니다.
3. 생성된 세계관과 캐릭터 속에서 자유롭게 대화를 진행합니다.
