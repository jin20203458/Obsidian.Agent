# GRC 사용자 퀵스타트 가이드 (User Quick Start Guide)

> **부제**: 비개발자 및 초보자를 위한 GRC 무설치 포터블 가이드

---

## 1. 다운로드 및 압축 해제

1. GRC 공식 저장소의 Releases 페이지에서 최신 버전의 **`GRC_vX.X.X_Portable.zip`** 파일을 다운로드합니다.
2. 다운로드한 ZIP 파일의 압축을 대상 폴더(예: `C:\GRC\`)에 먼저 완전히 해제합니다.
   * **주의**: ZIP 파일 내부에서 직접 `GRC.exe`를 실행하면 파일 경로 오류가 발생하므로 반드시 압축 해제 후 실행해야 합니다.

---

## 2. 프로그램 실행 (`GRC.exe`)

1. 압축이 해제된 폴더 내부에서 **`GRC.exe`**를 실행합니다.

### Windows SmartScreen 경고 대처법
코드 서명 미적용 오픈소스 특성상 첫 실행 시 **"Windows가 PC를 보호했습니다"** 경고창이 표시될 수 있습니다.

1. 경고창 내부의 **`추가 정보`**를 클릭합니다.
2. 창 하단에 표시되는 **`실행`** 버튼을 클릭합니다.
3. GRC는 개인정보를 수집하지 않는 MIT 라이선스 오픈소스 프로그램입니다.

---

## 3. 초기 1회 API 키 등록 방법

프로그램 실행 후 우측 상단의 **[설정]** 버튼을 클릭하여 통신용 키를 등록합니다.

### 방법 A: Google AI Studio 키 사용 (추천)
1. Google AI Studio API Key 발급 페이지(https://aistudio.google.com/apikey)에서 무료 API Key를 발급받습니다.
2. GRC 설정 화면의 **Gemini API Key** 입력창에 키를 입력하고 **[설정 저장]**을 클릭합니다.

### 방법 B: Google Cloud Vertex AI 사용 (TTS 낭독 연동)
1. 구글 클라우드 콘솔 IAM 및 행정 메뉴에서 서비스 계정을 생성하고 비공개 키 파일(`.json`)을 다운로드합니다.
   * **서비스 계정 역할(Role) 설정**: `Vertex AI 사용자` 및 `Cloud Text-to-Speech API 사용자` 역할을 부여합니다. (또는 `편집자` 역할도 사용 가능합니다)
2. GRC 설정 화면에서 **[서비스 계정 키 파일 선택...]** 버튼을 클릭하여 다운로드한 `.json` 파일 선택 시 자동 등록됩니다.
3. **Project ID**를 입력합니다.
4. **주의**: **Location(리전) 필드는 반드시 비워두어야 합니다.** (Gemini 3.6 Flash 모델 전용 global 엔드포인트 작동)
5. **[설정 저장]**을 클릭합니다.

---

## 4. 세션 생성 및 대화 시작

1. 메인 화면의 **[새 대화 시작]** 또는 **[AI 세션 아키텍트]** 버튼을 클릭합니다.
2. 주제 키워드를 입력하면 AI 세션 아키텍트가 캐릭터 설정, 스탯창, 로어북, 초기 시나리오를 자율 생성합니다.
3. 생성 완료 후 AI 캐릭터와 대화를 진행합니다.
