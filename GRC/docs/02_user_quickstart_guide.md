# GRC 사용자 퀵스타트 가이드 (User Quick Start Guide)

> **부제**: 비개발자 및 초보자를 위한 GRC 무설치 포터블 가이드
> **한 줄 요약**: 설치 프로그램이나 개발 환경(.NET SDK) 없이 다운로드 후 즉시 실행하여 AI 롤플레잉을 즐기는 방법 안내.

---

## 1. 다운로드 및 압축 해제

1. GRC 공식 저장소의 [Releases 페이지](https://github.com/jin20203458/GRC/releases)에서 최신 버전의 **`GRC_vX.X.X_Portable.zip`** 파일을 다운로드합니다.
2. 다운로드한 ZIP 파일의 압축을 원하시는 폴더(예: 바탕화면 또는 `C:\GRC\`)에 먼저 **완전히 해제**해 주세요.
   > ⚠️ **주의**: ZIP 파일 내부에서 직접 `GRC.exe`를 더블 클릭하여 실행하면 파일 경로 오류가 발생합니다. 반드시 먼저 압축을 해제한 뒤 실행하세요.

---

## 2. 프로그램 실행 (`GRC.exe`)

1. 압축이 해제된 폴더 내부에서 **`GRC.exe`** 아이콘을 더블 클릭하여 실행합니다.

### 🛡️ Windows SmartScreen 경고 대처법
개인 오픈소스 소프트웨어 특성상 첫 실행 시 파란색 경고창(**"Windows가 PC를 보호했습니다"**)이 표시될 수 있습니다.

1. 경고창 내부의 **`추가 정보`** 글자를 클릭합니다.
2. 창 하단에 새로 나타나는 **`실행`** 버튼을 클릭합니다.
3. GRC는 개인정보를 수집하지 않는 안전한 MIT 라이선스 오픈소스 프로그램입니다.

---

## 3. 초기 1회 API 키 등록 방법

프로그램 실행 후 우측 상단의 **⚙ (설정)** 버튼을 클릭하여 AI 모델 통신용 키를 등록합니다.

### 방법 A: Google AI Studio 키 사용 (추천 / 가장 간편함)
1. [Google AI Studio API Key 발급 페이지](https://aistudio.google.com/apikey) 접속 후 구글 계정으로 로그인합니다.
2. **Create API key** 버튼을 눌러 무료 API Key를 발급받습니다.
3. GRC 설정 화면의 **Gemini API Key** 입력창에 복사한 키를 붙여넣고 하단의 **[설정 저장]**을 누릅니다.

### 방법 B: Google Cloud Vertex AI 사용 (음성 TTS 낭독 포함)
1. 구글 클라우드 콘솔에서 서비스 계정 키 파일(`.json`)을 다운로드합니다.
2. GRC 설정 화면에서 **[서비스 계정 키 파일 선택...]** 버튼을 눌러 다운로드한 `.json` 파일을 고릅니다. (자동으로 안전하게 등록됩니다)
3. **Project ID**를 입력합니다.
4. ⚠️ **Location(리전) 필드는 반드시 비워두셔야 합니다.** (Gemini 3.6 Flash 모델은 글로벌 전용 엔드포인트에서 작동합니다)
5. **[설정 저장]**을 누릅니다.

---

## 4. 세션 생성 및 AI 대화 시작

1. 메인 화면의 **➕ (새 대화 시작)** 또는 **✨ (AI 세션 아키텍트)** 버튼을 누릅니다.
2. `"사이버펑크 세계관의 하수구 생존기"` 또는 `"판타지 왕국의 마법학교 수석 졸업생"` 처럼 원하시는 주제를 한 줄 입력합니다.
3. AI 세션 아키텍트가 캐릭터 설정, 스탯창, 로어북 지식, 초기 시나리오를 알아서 준비해줍니다.
4. 준비된 AI 캐릭터와 자유롭게 대화를 즐기시면 됩니다!
